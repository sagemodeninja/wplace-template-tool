# Local Installation

1. Download latest build package here: [releases](https://github.com/sagemodeninja/wplace-template-tool/releases).

2. Unzip `.zip` download package.

3. Load the unzipped files as unpacked extension. See tutorial [here](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked).

3. Refresh page!
